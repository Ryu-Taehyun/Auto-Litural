# Auto-Litural

[aleph-omega](https://aleph-omega.vercel.app) 의 아침·마무리 리추얼 입력을 자동으로 채워 주는 Playwright 스크립트입니다.
`csv/` 폴더의 문장에서 무작위로 골라 각 입력칸을 채웁니다.

> **저장 버튼은 누르지 않습니다.** 마지막 단계까지 채운 뒤 멈추니, 내용을 확인하고 직접 저장하세요.

## 준비물

- Windows
- Python 3
- Google Chrome (`C:\Program Files\Google\Chrome\Application\chrome.exe`)

## 실행

| 파일 | 하는 일 |
|---|---|
| `morning.cmd` | 아침 리추얼 (`main.py`) |
| `close.cmd` | 마무리 리추얼 (`close.py`) |

더블클릭하거나 터미널에서 `./morning.cmd`, `./close.cmd`로 실행합니다.
처음 실행하면 가상환경(`.venv`) 생성과 패키지 설치를 자동으로 합니다.

### 아침 리추얼

1. Chrome이 디버깅 모드(포트 9222)로 열립니다. 이미 열려 있으면 그대로 씁니다.
2. 구글 로그인 버튼이 눌리면 **로그인은 직접** 합니다.
3. 로그인이 끝나면 호흡 → 편안했던 장면 → 강점 → 동료 평가 → 긍정 목표 순서로 자동 입력됩니다.

### 마무리 리추얼

1. 실행하면 먼저 동료 이름을 묻습니다. 1~3명을 띄어쓰기나 쉼표로 구분해 입력합니다. (예: `홍길동 이상혁`)
2. Chrome이 열리고, 로그인 후 강점 행동 돌아보기 → 감사 나누기 → 감사일기가 입력됩니다.
3. 동료 수에 맞춰 입력 줄이 자동으로 늘거나 줄어듭니다.

사이트 규칙상 **오늘 아침 리추얼을 저장해야** 마무리 리추얼로 넘어갈 수 있습니다.

## 구조

```
morning.cmd / close.cmd   실행 파일 (_setup.cmd 를 호출)
_setup.cmd                가상환경 생성 + 패키지 설치 + 스크립트 실행
main.py                   아침 리추얼
close.py                  마무리 리추얼
chrome.py                 Chrome 디버깅 모드 실행, 로그인 대기
requirements.txt          패키지 목록
csv/                      입력할 문장 (한 줄에 문장 하나)
```

### 문장 바꾸기

`csv/` 안의 파일에 한 줄씩 문장을 추가하거나 고치면 됩니다. 실행할 때마다 무작위로 하나씩 뽑습니다.

| 파일 | 쓰이는 곳 |
|---|---|
| `Title.csv`, `1.csv` ~ `7.csv`, `Name.csv` | 아침 리추얼 |
| `close_*.csv` | 마무리 리추얼 |

## 알아둘 점

- 로그인용 Chrome 프로필은 `%LOCALAPPDATA%\ChromeDebug`에 따로 저장됩니다. 평소 쓰는 프로필과 섞이지 않습니다.
- 호흡 단계는 "5분 시작" 직후 "여기까지"를 눌러서, 호흡 시간이 거의 0분으로 기록됩니다.
- 아이디나 비밀번호는 스크립트에 넣지 않았습니다.

## 문제 해결

| 증상 | 원인 / 해결 |
|---|---|
| `bash main.py`에서 `import: command not found` | 파이썬 파일을 셸로 실행해서 생기는 오류입니다. `morning.cmd`를 쓰거나 `python main.py`로 실행하세요. |
| 로그인 후 멈춤 | 로그인 뒤 이동 위치가 `/tutorial` 또는 `/cortex`입니다. 둘 다 기다리도록 되어 있습니다. |
| `기록 수정하기` 에서 실패 | 오늘 첫 기록이면 이 버튼이 없습니다. 있을 때만 누르도록 되어 있습니다. |
| 첫 단계에서 안 넘어감 | 호흡 단계에서 "5분 시작" → "여기까지"를 눌러야 합니다. 사이트가 바뀌면 입력칸 id가 달라질 수 있으니 `main.py`와 `close.py`의 선택자를 확인하세요. |
| `Chrome not found` | `chrome.py`의 `CHROME` 경로를 설치 위치에 맞게 고치세요. |
